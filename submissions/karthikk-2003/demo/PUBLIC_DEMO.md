# SYNTHETIC / DEMONSTRATION DATA

The restricted hosted demo seeds two records, SYNTHETIC-DEMO-001 and
SYNTHETIC-DEMO-002, using returns_manager.deployment.seed_demo.
Their identifiers, order context and fixed capture timestamp are synthetic.
There are no photographs, model responses, human assertions or real product facts.
Source hashes identify generated fixture data, not product authenticity.
Both records demonstrate missing-evidence uncertainty and pending review.

The seed is repeatable, preserves existing identical records/history, and rejects
unexpected scoped review cases. It does not copy developer data or load the
headphones photograph. See [deployment instructions](../DEPLOYMENT.md).

The older headphones package remains a separate local demonstration requiring
its authorized private image; it is not distributed with the hosted demo.
